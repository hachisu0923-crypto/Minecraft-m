# 06 - アセットとデータ

`src/main/resources` 配下は **パスと名前が仕様で固定**されている。
1文字でも違うと読み込まれない（紫黒・無効化）。名前空間は常に `examplemod`（= mod id）。

## assets（クライアント側）

```
assets/examplemod/
├── lang/<locale>.json                  例: en_us.json / ja_jp.json
├── models/item/<name>.json             アイテム/手持ちモデル
├── models/block/<name>.json            設置ブロックモデル
├── blockstates/<name>.json             ブロック状態 → モデル対応
└── textures/
    ├── item/<name>.png
    ├── block/<name>.png
    └── entity/<name>.png               エンティティのテクスチャ（プレイヤー型は 64x64）
```

### lang
`<key>: <表示名>` の単純な JSON。キー規約:
- アイテム: `item.examplemod.<name>`
- ブロック: `block.examplemod.<name>`
- エンティティ: `entity.examplemod.<name>`
- クリエイティブタブ: `itemGroup.examplemod.<tab>`

**en_us は必ず用意**（フォールバック先）。日本語表示用に ja_jp も用意する。

### model（item）
- 単純アイテム: `{ "parent": "item/generated", "textures": { "layer0": "examplemod:item/<name>" } }`
- ブロックの手持ち: `{ "parent": "examplemod:block/<name>" }`

### model（block）
- 全面同一テクスチャ: `{ "parent": "block/cube_all", "textures": { "all": "examplemod:block/<name>" } }`
- 面ごとに変える: `block/cube`（`up`/`down`/`north`/... を指定）

### blockstate
最小形（向きなし）:
```json
{ "variants": { "": { "model": "examplemod:block/<name>" } } }
```
向き/状態がある場合は `variants` のキーをプロパティ（例 `"facing=north"`）にする。

### textures
PNG（推奨 16x16, RGBA）。`<name>` はモデルの `textures` 参照と一致させる。

## data（サーバ/データ駆動）

```
data/examplemod/
├── loot_tables/blocks/<name>.json      ブロック破壊ドロップ
├── recipes/<name>.json                 クラフト等のレシピ
├── tags/blocks/<group>.json            ブロックタグ（採掘可否など）
├── tags/items/<group>.json             アイテムタグ
├── advancements/<name>.json            進捗（任意）
└── capabilities/weapons/<item>.json    Epic Fight 武器 capability（`docs/epicfight/11`）
```

### recipe（例）
形なし（shapeless）:
```json
{
  "type": "minecraft:crafting_shapeless",
  "ingredients": [ { "item": "minecraft:stone" } ],
  "result": { "item": "examplemod:example_item" }
}
```
形あり（shaped）:
```json
{
  "type": "minecraft:crafting_shaped",
  "pattern": ["XXX","X X","XXX"],
  "key": { "X": { "item": "examplemod:ruby" } },
  "result": { "item": "examplemod:ruby_block" }
}
```

### loot_table
ブロックドロップは `loot_tables/blocks/<name>.json`。基本形は `docs/05` 参照。

### tags
タグはバニラ/他 Mod の挙動に紐付く。例: ツルハシで掘れるようにする
`data/minecraft/tags/blocks/mineable/pickaxe.json` に
`{ "replace": false, "values": ["examplemod:ruby_block"] }`。
**名前空間が `minecraft` のタグは `data/minecraft/...` に置く**点に注意。

## data generation（任意・上級）

手書きの JSON を自動生成したい場合、`./gradlew runData` を使う。
- `build.gradle` の `data` run 設定が `src/generated/resources` に出力
- 生成出力は `sourceSets.main.resources` に取り込まれる（build.gradle 設定済み）
- Provider（`ItemModelProvider` / `BlockStateProvider` / `RecipeProvider` / `LootTableProvider` 等）を
  `GatherDataEvent`（Mod バス）で登録する
- 量産フェーズで有効。最初は手書きで十分。`src/generated/resources` はコミットしない（`.gitignore` 済み）
