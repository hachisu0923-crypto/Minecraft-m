# 01 - 環境構築

## 必要なもの

| 項目 | バージョン | 備考 |
|---|---|---|
| JDK | **17**（必須・固定） | Forge 1.20.1 は 17 でのみ動作。21 等は不可 |
| Gradle | 8.1.1 | `./gradlew` が自動取得。手動インストール不要 |
| ForgeGradle | 6.0 | `build.gradle` の plugins で取得 |
| Forge | 47.4.10（1.20.1 Recommended） | `gradle.properties` の `forge_version` |

JDK17 の入手例: Eclipse Temurin 17 / Microsoft Build of OpenJDK 17。
インストール後、`JAVA_HOME` を JDK17 に向けるか、PATH を通す。

## 実行 JDK が 17 でない場合（重要）

`build.gradle` は Java toolchain を 17 に固定している:

```groovy
java { toolchain.languageVersion = JavaLanguageVersion.of(17) }
```

- Gradle 自体は新しい JDK（例: 21）で起動してよい。**コンパイルは toolchain の 17 が使われる**
- ただし JDK17 が PATH / よくある場所に **存在しない** と toolchain 解決に失敗する
- 解決策: JDK17 をインストールする。確認: `./gradlew -q javaToolchains`
- 自動プロビジョニングは設定していない（依存を増やさないため）。JDK17 は手動で用意する

## 主要な Gradle タスク

| タスク | 説明 |
|---|---|
| `./gradlew build` | コンパイル + jar 生成（`build/libs/`） |
| `./gradlew runClient` | 開発用 Minecraft クライアント起動。GUI 必須 |
| `./gradlew runServer` | 開発用サーバ起動（`--nogui`） |
| `./gradlew runData` | data generation 実行（`src/generated/resources` 出力） |
| `./gradlew --refresh-dependencies build` | 依存キャッシュを無視して再取得 |
| `./gradlew clean` | `build/` を削除 |

## 初回ビルドとネットワーク

初回 `build` は以下から取得する:
- `https://maven.minecraftforge.net/`（Forge / ForgeGradle）
- `https://libraries.minecraft.net/`（Minecraft ライブラリ）
- `https://services.gradle.org/`（Gradle 配布物）

これらが遮断された環境ではビルドは完了しない。切り分けは `docs/07` を参照。
`./gradlew --version` は `services.gradle.org` のみで完結するため、遮断環境でも動くことがある。

## IDE（任意）

- IntelliJ IDEA / Eclipse どちらも可。`build.gradle` に `idea` / `eclipse` プラグイン適用済み
- IDE で開く前に一度 `./gradlew build` を通すと、Minecraft/Forge のソースが解決される
- 実行構成は ForgeGradle が `runClient` / `runServer` を生成する
