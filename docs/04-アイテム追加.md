# 04 - アイテム追加

コピー元: `src/main/java/com/example/examplemod/registry/ModItems.java`
例として `ruby` というアイテムを足す手順で説明する（名前は読み替える）。

## 手順

### 1. 登録（ModItems.java）

```java
public static final RegistryObject<Item> RUBY =
        REGISTER.register("ruby", () -> new Item(new Item.Properties()));
```

- `register` の第1引数（`"ruby"`）が **レジストリ名**。以後すべてこの名前で参照
- 食べ物・道具などは `Item.Properties()` や `Item` のサブクラスを変える（例: `new Item(new Item.Properties().food(...))`）
- `ModItems.REGISTER` は `ExampleMod` で既に register 済みなので、新クラスを作らない限り追加作業は不要

### 2. アイテムモデル JSON

`src/main/resources/assets/examplemod/models/item/ruby.json`

```json
{
  "parent": "item/generated",
  "textures": { "layer0": "examplemod:item/ruby" }
}
```

### 3. テクスチャ PNG

`src/main/resources/assets/examplemod/textures/item/ruby.png`（16x16, RGBA 推奨）

仮テクスチャを作る例（stdlib のみ・単色）:
```bash
python3 - <<'PY'
import zlib,struct,os
def png(p,rgba):
    raw=bytearray()
    for _ in range(16):
        raw.append(0)
        for _ in range(16): raw+=bytes(rgba)
    def c(t,d): return struct.pack(">I",len(d))+t+d+struct.pack(">I",zlib.crc32(t+d)&0xffffffff)
    os.makedirs(os.path.dirname(p),exist_ok=True)
    open(p,"wb").write(b'\x89PNG\r\n\x1a\n'+c(b'IHDR',struct.pack(">IIBBBBB",16,16,8,6,0,0,0))+c(b'IDAT',zlib.compress(bytes(raw),9))+c(b'IEND',b''))
png("src/main/resources/assets/examplemod/textures/item/ruby.png",(220,40,60,255))
PY
```

### 4. 名前（lang）

`assets/examplemod/lang/en_us.json` と `ja_jp.json` の両方に追加:

```json
"item.examplemod.ruby": "Ruby"
```
```json
"item.examplemod.ruby": "ルビー"
```

キー形式は `item.<modid>.<レジストリ名>`。

### 5. クリエイティブタブに載せる（任意だが推奨）

`ModCreativeTabs.java` の `displayItems` 内に追加:

```java
output.accept(ModItems.RUBY.get());
```

### 6. レシピ（任意）

`data/examplemod/recipes/ruby.json` 等。形式は `docs/06`。

## よくある失敗

| 症状 | 原因 |
|---|---|
| アイテムが紫黒 | `models/item/*.json` または `textures/item/*.png` 不足/名前不一致 |
| 名前が `item.examplemod.ruby` のまま表示 | lang キーの綴り違い / ファイル未追加 |
| クラッシュ（registry not present） | `.get()` をクラスロード時に呼んでいる |
