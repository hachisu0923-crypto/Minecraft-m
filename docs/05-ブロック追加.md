# 05 - ブロック追加

コピー元: `src/main/java/com/example/examplemod/registry/ModBlocks.java`
例として `ruby_block` を足す手順（名前は読み替える）。

ブロックは **Block 本体 + その BlockItem（手持ち/インベントリ用）** の 2 つを登録する。
さらにアセットが多い（blockstate / block model / item model / texture / loot_table / lang）ので
**1つでも欠けると紫黒や無音ドロップ**になる。チェックリストで必ず確認する。

## 手順

### 1. 登録（ModBlocks.java）

```java
public static final RegistryObject<Block> RUBY_BLOCK =
        REGISTER.register("ruby_block", () -> new Block(
                BlockBehaviour.Properties.of()
                        .mapColor(MapColor.COLOR_RED)
                        .strength(4.0F, 6.0F)
                        .requiresCorrectToolForDrops()));

public static final RegistryObject<Item> RUBY_BLOCK_ITEM =
        ModItems.REGISTER.register("ruby_block",
                () -> new BlockItem(RUBY_BLOCK.get(), new Item.Properties()));
```

- `BlockBehaviour.Properties.of()`（1.20.1 は引数なし。Material は廃止）
- `.strength(hardness, resistance)` / `.requiresCorrectToolForDrops()` / `.mapColor(...)` などで調整
- BlockItem は **Item レジストリ側**に、ブロックと同じレジストリ名で登録する

### 2. blockstate

`assets/examplemod/blockstates/ruby_block.json`

```json
{ "variants": { "": { "model": "examplemod:block/ruby_block" } } }
```

### 3. ブロックモデル

`assets/examplemod/models/block/ruby_block.json`

```json
{ "parent": "block/cube_all", "textures": { "all": "examplemod:block/ruby_block" } }
```

### 4. アイテムモデル（手持ち表示）

`assets/examplemod/models/item/ruby_block.json`

```json
{ "parent": "examplemod:block/ruby_block" }
```

### 5. テクスチャ

`assets/examplemod/textures/block/ruby_block.png`（16x16）。生成例は `docs/04` の Python スニペット（パスを `textures/block/` に変更）。

### 6. loot table（破壊ドロップ）

`data/examplemod/loot_tables/blocks/ruby_block.json`

```json
{
  "type": "minecraft:block",
  "pools": [
    {
      "rolls": 1,
      "entries": [ { "type": "minecraft:item", "name": "examplemod:ruby_block" } ],
      "conditions": [ { "condition": "minecraft:survives_explosion" } ]
    }
  ]
}
```
これが無いとブロックを壊しても何も落ちない。

### 7. lang

`lang/en_us.json` と `ja_jp.json` の両方:
```json
"block.examplemod.ruby_block": "Ruby Block"
```
```json
"block.examplemod.ruby_block": "ルビーブロック"
```

### 8. クリエイティブタブ（推奨）

`ModCreativeTabs.java` の `displayItems` に:
```java
output.accept(ModBlocks.RUBY_BLOCK_ITEM.get());
```

## よくある失敗

| 症状 | 原因 |
|---|---|
| 設置ブロックが紫黒 | blockstate または block model または texture 不足/名前不一致 |
| 手持ちが紫黒 | `models/item/<name>.json` 不足 |
| 壊しても何も落ちない | loot_table 不足（または名前不一致） |
| 素手で壊すとドロップしない | `.requiresCorrectToolForDrops()` 指定。仕様どおりなら正常 |
